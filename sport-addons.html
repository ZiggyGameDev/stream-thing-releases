For addon makers

Sport addons

DizziTV's Sport pages track every match, but the app doesn't come with streams. When someone presses Watch on a match, DizziTV asks the addons they've installed, using the ordinary Stremio addon protocol. This page explains how an addon shows up there.

If your addon already lists events

Nothing to change. For a match, DizziTV looks through each installed addon's catalogues that aren't films or shows (types like tv, channel or events):

  • A catalogue that takes a search extra is searched for the home side's name (or the event's, for a race or a tournament). Others are listed as they are.
  • An entry counts as the match when its name or description names both sides. Full names, short names and names without "FC" or "City" all count, but "Manchester United" never matches Manchester City. For an event without sides, most of the words in its title have to be there.
  • The entry's streams are then asked for as usual: /stream/<type>/<id>.json.

So the clearer an entry's name ("Lincoln City vs Wrexham"), the more reliably it's found. Up to six catalogues of each addon are looked at, the searchable ones first.

Answering for a match directly

An addon can also answer for DizziTV's own match ids, with no catalogue at all. Declare the sport type and the sport: id prefix:

{
  "id": "example.sport",
  "version": "1.0.0",
  "name": "My sport streams",
  "resources": ["stream"],
  "types": ["sport"],
  "idPrefixes": ["sport:"],
  "catalogs": []
}

DizziTV then asks /stream/sport/sport:<event id>.json, and you answer with { "streams": [...] } as for any title. The event id says where the match comes from:

  • espn-401880158: an ESPN event (its id is ESPN's, so you can look the match up there);
  • espn-<id>-<session>: one session of a Formula 1 weekend;
  • espn-cricket-<id>, tsdb-<id> (TheSportsDB), wiki-darts-… and wiki-snooker-… for the rest.
